# M2 样张

- `sample.png`：480×270 样张按 4 倍最近邻放大为 1920×1080；这是素材 sheet，游戏画布仍为 320×180。
- `sample-logical.png`：样张逻辑像素原图。
- `characters.js`：四只角色的统一像素定义；前端通过 `render.js` 引用。
- 各角色 PNG 是同一份定义的导出，不应另行修改。
- `card-*.png`：16×22；数字图形为 7×9，角花为 7×7；`shell.png` 为 160×90。
- 文字使用官方 Google Fonts 的 DotGothic16；通过二值蒙版渲染，无抗锯齿。牌背为浅蓝底原创海胆图案，16×22。
- 生成命令：`python3 art/build.py`（Pillow 11.3.0）。
- 白名单验证对最终样张所有像素执行，当前 45 色，白名单外为零。
- SPEC 优先于 skill：眼睛使用 2×2、一格白高光；棕色海獭及全部颜色按 SPEC。
- 简化桌面及三个特效各一帧；不是完整动画。
- 待音音批准样张后再铺开页面；未做任何页面和动画集成。
