# 像素海洋风

## 画法

- 一格一个字符的格子图：`.` 是空，别的字符查这张图自己的调色板。画布小：头像 16–32 格，按钮和图标 20–28 格，背景按屏幕大小算。
- 只按整数倍放大，关掉平滑（canvas 设 `imageSmoothingEnabled = false`，CSS 用 `image-rendering: pixelated`）。不用 SVG 拼小方块，缝上会糊出细线。
- 描边：形状里贴着空格的那一圈，换成同色系更深的一档。不用纯黑描边。
- 光影只靠换一档颜色：左上一两格高光，不用渐变、阴影、圆角矢量。
- 角色带脸：3×3 的大圆眼、两点白色高光，两格粉色腮红。海獭的鼻子是正三角（▲）。
- 动画一帧 80ms 左右，循环的首尾两帧要接得上。

## 气质

- 界面元素就是海里的生物本身：按钮是河豚、珍珠、海胆，小 tab 是一条横着的鱼，输入框是一条鲸鲨，加号是一只水母。不要"圆底加图标"。
- 温和、胖乎乎、可爱。
- 白天的海和夜里的海两套：深色模式只换水和风景，角色颜色不变。

## 这次 hackathon 的规矩

- 照这里的风格画新的图。不要搬她以前任何仓里的像素图或画图代码（minasoko、InKieran 的 pixel-icons、minamo、etude 等），比赛规定不能用之前做过的东西。
- 先做模板：数字牌用一张模板按颜色和数字生成；只有功能牌和头像单独画。
- 先出一张预览（sheet）给她看，她点头了再铺开。
